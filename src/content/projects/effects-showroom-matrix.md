# 93+ 原生 Web 动效与交互沙盒矩阵

本项目是前端视觉表现力与人机微交互的实验库。

## 产品与技术亮点

- **零外部依赖框架侵入**：93 个动效均以独立 HTML/CSS/JS 沙盒封装，互不污染全局环境。
- **即时交互验证**：支持在主站内通过弹窗无刷新内嵌试玩，也可一键全屏独立运行。
- **分类覆盖**：涵盖 3D警车、海底泡泡多角鱼、彩色时钟、飞机大战与物理重力小球等。
