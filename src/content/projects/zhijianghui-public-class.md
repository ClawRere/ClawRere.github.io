## 1. 问题与目标
面向寒暑假期间全省中小学生自主学习与素养拓展场景，传统线上课程存在**参与入口分散、优质名师供给不足、学校动员链路断层以及缺乏持续学习激励**等问题。项目核心目标是构建一条可复用、低门槛的公益课堂交付链路，把教育产品设计与跨组织运营资源整合到同一个平台闭环中。

## 2. 本人职责
在 2019–2020 年之江汇寒暑假公益课堂系列项目中，本人负责：
- **产品功能设计**：梳理并设计从「课程发现 → 报名/参与 → 互动学习 → 成果展示 → 运营反馈」的完整用户端功能流程。
- **活动策划与规则设计**：制定寒暑假公益主题活动方案、打卡/激励机制与阶段性运营节奏。
- **外部资源统筹**：直接负责**名师邀约、合作学校邀约及第三方赞助资源对接**，保障优质内容供给与活动奖励落地。

## 3. 产品与跨组织协作过程
本项目构建了四方协同交付网络：
1. **平台 / 产品团队**：落地专题活动页面、选课报名、互动打卡与数据监控能力。
2. **名师与合作学校**：引入一线名师录制精品公益课，通过学校端通知触达目标学生群体。
3. **第三方赞助资源**：引入外部生态伙伴提供活动奖品与公益激励支持。
4. **学生与家长**：通过清晰的活动专题页一键直达课程，形成寒暑假自主学习习惯。

## 4. 可核对结果与边界说明
- 历史材料记录 **2019 年寒假公益课堂约 30 万人参与**（说明：该数字对应特定期次活动记录，严格区分于之江汇整个省级平台的累计总访问量，不将平台级宏观数据归因于个人项目）。
- 连续两届顺利完成线上活动专题上线、跨校联动及资源交付闭环。
